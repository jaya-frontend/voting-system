Voting System

A simple Voting System built using JavaScript "Map" and "Set".

Features

- Add new voting options.
- Cast votes for different options.
- Prevent duplicate votes from the same voter ID.
- Display poll results.
- Count votes for each option.

Technologies Used

- HTML5
- CSS3
- JavaScript
- JavaScript Map and Set

Live Demo

https://jaya-frontend.github.io/voting-system/

GitHub Repository

https://github.com/jaya-frontend/voting-system

How It Works

1. Add a new voting option.
2. Enter your voter ID.
3. Select an option to cast your vote.
4. Click Show Results to view the voting results.
